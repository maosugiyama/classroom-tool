# 文献フォルダ整理ルール（CLAUDE.md）

このファイルは `/Users/mao/Documents/文献` フォルダの直下に置いてください。
Claude Code はこのフォルダで起動されたとき、以下のルールに従って文献PDFを整理します。

## 対象

- 「ダウンロード」フォルダ（`~/Downloads`）と「デスクトップ」（`~/Desktop`）にある学術文献のPDF
- 文献フォルダ直下に未分類のまま置かれているPDF

**注意：文献（論文・書籍・資料のPDF）以外のファイルには絶対に触らないこと。**
文献かどうか判断に迷うファイルは、必ずユーザーに確認する。

## 作業の流れ（この順番を必ず守る）

1. **サブフォルダの確認** — まず `ls` で文献フォルダに実在するサブフォルダを一覧表示する。存在しないフォルダ名を勝手に想定しない。
2. **書誌情報の読み取り** — 各PDFについて `_tools/bunken_inspect.py` を実行し、著者・年・タイトルを把握する。
   ```
   python3 _tools/bunken_inspect.py "PDFのパス"
   ```
3. **提案** — 各PDFについて「新しいファイル名」と「移動先サブフォルダ」を表にして提案する。既存のサブフォルダに合うものがなければ、新しいカテゴリ名を提案する（作成はまだしない）。
4. **承認待ち** — ユーザーの承認（OK）をもらってから次へ進む。勝手に移動しない。
5. **移動** — 承認された内容で `mv` によりリネームと移動を行う。元ファイルの削除やコピーではなく「移動」を使う。同名ファイルが既にある場合は上書きせず、ユーザーに報告する。
6. **目録への記録** — 文献フォルダ直下の `目録.md` に1行追記する（無ければ作成する）。

## ファイル命名ルール

既存ファイル（例：`mizoguchi2022notion.pdf`）に合わせ、次の形式とする：

```
著者姓（ローマ字・小文字）+ 出版年 + キーワード1語 .pdf
例: mizoguchi2022notion.pdf
```

- 著者が2名: `姓1_姓2` を使う（例: `tanaka_sato2020media.pdf`）
- 3名以上・編著: 筆頭著者姓 + `etal` / 編者なら `eds`（例: `gritsenko_etal2021digitalrussia.pdf`）
- キーワードは内容を表す英単語1〜2語（小文字、スペースなし）
- 日本語著者はヘボン式ローマ字にする

## 目録（目録.md）の形式

| ファイル名 | 著者 | 年 | タイトル | カテゴリ | 追加日 |
|---|---|---|---|---|---|

- タイトルは原語のまま記録する
- カテゴリは移動先サブフォルダ名
- 追加日は作業当日の日付（YYYY-MM-DD）

## 禁止事項

- ユーザーの承認なしにファイルを移動・リネーム・削除しない
- 文献以外のファイル（写真、書類、アプリ等）に触らない
- 既存ファイルを上書きしない
- 文献フォルダの既存のサブフォルダ構成を勝手に変更しない
