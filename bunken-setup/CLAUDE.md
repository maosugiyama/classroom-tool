# 文献フォルダ 整理ルール（Claude Code 用指示書）

このファイルは「文献」フォルダの直下に置いてください。
Claude Code はこのフォルダ内で作業する際、必ず本ルールに従うこと。

## 目的

新しく追加された PDF（および docx / epub）の文献ファイルを、
(1) 書誌情報を確認し、(2) 命名規則に従ってリネームし、(3) 適切なカテゴリのサブフォルダへ移動する。

## ワークフロー

新規ファイルの整理を依頼されたら、次の手順を必ず順番に実行する。

1. `_tools/bunken_inspect.py <ファイル>` を実行し、メタデータと冒頭テキストを取得する。
   - スクリプトが使えない環境では `pdfinfo` と `pdftotext -f 1 -l 6` で代用してよい。
2. 出力から **著者（または編者）・刊行年・タイトル・種別（book / chapter / article）** を判定する。
   メタデータが空・不正確な場合は必ず標題紙（冒頭ページ）のテキストを優先する。
3. 下記の命名規則でファイル名を決定する。
4. 下記のカテゴリ判定表に従い移動先サブフォルダを決定する。判定に迷う場合は
   **勝手に移動せず、候補を2つ提示してユーザーに確認する。**
5. `git mv` は使わず、通常の `mv` でリネーム・移動する。実行前に必ず
   「旧名 → 新名（移動先）」の一覧を提示し、ユーザーの承認を得てから実行する。
6. 最後に `_tools/文献目録.csv` に1行追記する（無ければ作成する）。
   列: 追加日, ファイル名, 著者, 年, タイトル, カテゴリ, DOI/ISBN

## 命名規則

```
著者姓_年_短縮タイトル.pdf
```

- 著者は **姓のみ**、3名までアンダースコアで連結。4名以上は `第一著者姓_et_al`。
- 編著の場合は姓の列の直後に `_eds`（単独編者は `_ed`）を付ける。
- 年は西暦4桁。不明な場合は `nd`。
- 短縮タイトルは英語文献なら英語のまま、冠詞（The/A/An）は省略可。
  日本語文献は日本語のまま、ロシア語文献は **ロシア語表記のままでよい**
  （翻字しない。ѣ 等の旧正書法もタイトルにあればそのまま保持）。
- 空白はアンダースコアに置換。コロン以降のサブタイトルは原則省略。
- ファイル名にカッコ・カンマ・スラッシュは使わない（LaTeX やスクリプトでの事故防止）。

例:
- `Gritsenko_Wijermars_Kopotev_eds_2021_Palgrave_Handbook_of_Digital_Russia_Studies.pdf`
- `Bakich_2002_Valerii_Pereleshin.pdf`
- `Забияко_Эфендиева_2009_Меж_двух_миров.pdf`
- `杉山_2026_亡命主体の可読性.pdf`

## カテゴリ判定表

判定はタイトル・目次・冒頭テキストのキーワードに基づく。上から順に評価し、最初に該当したものを採用する。
（サブフォルダ名は既存の「文献」フォルダの構成に合わせて適宜読み替えること。
 実際のフォルダ構成と食い違う場合は、まず `ls` で実在するサブフォルダを確認し、
 最も近いものを提案する。）

複数カテゴリにまたがる文献（例: 本書のような DH × ロシア研究）は、
**研究上の利用目的が近い方** を優先し、迷う場合はユーザーに確認する。

## 禁止事項

- 元ファイルの削除（リネーム・移動のみ。上書きの恐れがある場合は必ず停止して確認）
- ユーザーの承認なしの一括リネーム
- OCR やファイル内容の改変（整理の範囲外）
