# 文献フォルダ セットアップ一式

Macの `~/Documents/文献` フォルダをClaude Codeで整理するためのファイルです。

## 配置場所

| このフォルダのファイル | Macでの置き場所 |
|---|---|
| `CLAUDE.md` | `文献` フォルダの直下 |
| `_tools/bunken_inspect.py` | `文献/_tools/` の中（`_tools`フォルダは新規作成） |

## 使い方（毎回の手順）

1. ターミナルを開き `cd ` と入力し、Finderから「文献」フォルダをドラッグ&ドロップしてEnter
2. `claude` と入力してEnter（初回のみ `/login` でログイン）
3. 次のプロンプトを貼り付けてEnter：

```
ダウンロードフォルダとデスクトップにある文献PDFを、CLAUDE.mdのルールに従ってこのフォルダに整理してください。
まず実在するサブフォルダを確認し、各PDFの移動先とファイル名を提案してから、承認後に移動と目録への記録を行ってください。
デスクトップの文献以外のファイルには触らないでください。
```

4. 提案内容を確認し、問題なければ承認（`y` またはEnter）
